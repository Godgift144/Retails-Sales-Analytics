# Retail Sales Analytics Dashboard

A 5-week end-to-end data analysis project using the Superstore Sales dataset (9,994 orders, 793 customers) to analyze sales performance, profitability, and customer behavior — built in Excel and Power BI.

## Business Objective
Analyze retail sales performance, customer purchasing behavior, and product performance to identify trends, opportunities, and areas requiring management attention.

## Project Structure
- `01_Raw_Data/` — original Superstore dataset
- `02_Cleaned_Data/` — cleaned dataset (Excel)
- `03_Analysis/` — KPI, product, customer, and cohort analysis
- `04_Dashboard/` — interactive Power BI dashboard
- `05_Report/` — business documentation and executive summary
- `06_Presentation/` — final presentation

## Tools
Excel (Power Query, PivotTables) · Power BI (Power Query, DAX, Data Model)
